# jordan_mcgrath_honours_thesis
Contains R code used in the thesis written by Jordan McGrath at Griffith University (2026), and relevant data used.

Some data were too large to commit. Those I couldn't upload were accessed at:
- Australia’s River Basins 1997, which was accessed on the Geoscience Australia website.
- GEODATA 9 second digital elevation model (DEM), which was accessed on the Geoscience Australia website.
- The 2021 states and territories shapefile from the ‘Geocentric Datum of Australia 2020’ digital boundary files on the Australian Bureau of Statistics website. The Queensland boundary files were also accessed here.
